# Welcome to the Document Review Agent

This tool helps you ingest, analyze, and restructure any document through a streamlined four-phase workflow.

## How It Works

### Phase 1: Ingestion & Analysis
The system automatically detects your document type, converts it to Markdown, extracts images, and analyzes the structure. You'll get a comprehensive report with statistics, quality assessment, and recommendations.

**Tip:** Documents with clear heading hierarchies (H1, H2, H3) work best for optimal results.

### Phase 2: Chunking & Indexing
Configure how the document should be split into manageable sections. You can preview the chunking strategy before applying it. This helps break down large documents for better processing.

**Tip:** Use "Split by H2" for most documents. For very long documents, consider H1-level chunking.

### Phase 3: Template Mapping & Refinement
Map your document sections to a predefined outline template. The AI will suggest improved titles and identify sections that need attention.

**Tip:** Review unmapped sections carefully—they might contain important content that doesn't fit the template structure.

### Phase 4: Review & Interact
Review your refined document with AI-improved titles highlighted. Use the chatbot to ask questions about any part of the document. You can select text from the document to ask about specific passages.

**Tip:** Select text from the document viewer and ask questions—the chatbot will use that context to provide more accurate answers.

## Getting Started

1. **Upload a document** or select one from the left sidebar
2. **Start Phase 1** to begin analysis
3. **Follow the workflow** through each phase
4. **Use the chatbot** at any time for help or to ask questions about your document

The chatbot is always available in the right panel and is aware of your current workflow state. Feel free to ask questions at any time!
