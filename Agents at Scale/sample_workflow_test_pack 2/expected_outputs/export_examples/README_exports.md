# Export Examples (Golden Files)

These files are optional golden outputs for validating export conversion.

- `policy_with_table_export.md`  → expected Markdown export (same as R3 report)
- `csv_ticket_router_export.csv` → expected compiled CSV export
- `future_docx_export.docx` and `future_pdf_export.pdf` can be added if you want strict binary diff tests.
