# Step 3 — Produce Final Report (Markdown)

## Goal
Turn the prior step outputs into a concise Markdown report.

## Inputs
- R1: obligations JSON
- R2: gaps JSON
- R0: original document

## Instructions
- Output **Markdown** only (no JSON).
- Keep it executive-friendly.
- Include:
  - Summary
  - Obligations table (Type, Statement, Section)
  - Gaps table (Severity, Gap, Related Obligation)
  - Questions (if any)

## Formatting
Use Markdown tables. Keep lines reasonably short.
