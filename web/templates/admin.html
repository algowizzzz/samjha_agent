            🤖 Agentic Workflows Builder

            Create and manage AI-powered agentic workflows. Design multi-step templates for document review, data extraction, compliance checks, and risk assessments.

            Create New Agent WF

            Give your agentic workflow template a clear, descriptive name that indicates its purpose. This name will appear in the agentic workflow selection menu for users.
            Provide a clear explanation of what this agentic workflow does, when to use it, and what outputs to expect (optional, up to 500 words).
            Select the business areas this agentic workflow applies to (comma-separated). Common domains: Risk, Finance, Compliance, Credit, Operations, Legal, Audit. This helps users find the right template for their needs.
            Select the file formats this agentic workflow can process. PDF is recommended for documents with complex formatting, while DOCX and TXT work well for simpler documents. CSV may require specialized processing.
            Use AI vision model to transcribe documents by converting PDF pages to images. Useful for scanned documents or complex layouts.
            Instructions for extracting text from document images. Default prompt will be used if empty.
            Higher DPI = better quality but more tokens/cost
            PNG preserves quality, JPEG reduces file size
            50 (Smaller) 85 100 (Better)
            Opus = best quality, Haiku = fastest/cheapest
            Maximum tokens per page response (1024-16384)
            0.0 (Deterministic) 0.0 1.0 (Creative)
            Lower = more consistent extraction (recommended: 0.0)
            Define the AI analysis sequence. Each step processes the output from the previous step. Common patterns: 1) Summarize → 2) Extract tables → 3) Analyze risks, or 1) Extract key facts → 2) Identify compliance requirements → 3) Generate recommendations. The first step always processes the original document, subsequent steps process previous outputs (Response 1, Response 2, etc.).
            Select your preferred output format. Markdown is human-readable and perfect for reports, documentation, and audit trails. JSON enables automated processing and integration with other systems. CSV is ideal for tabular data extraction. Excel creates spreadsheets with multiple sheets (one per table).
