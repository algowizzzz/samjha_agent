Welcome to the Beginner Software Development Bootcamp! This 4-week intensive course will take

second mini-project will solidify these skills.

learning about HTTP, the request-response cycle, and building web applications with Flask. You’ll
create routes, work with templates (HTML/CSS), handle user input via forms, and possibly serve
dynamic content. A Flask mini-project will help practice these concepts.
• Week 4 – Capstone Project and Advanced Topics: Integrate everything you’ve learned to build
a capstone full-stack web application using Flask, including a backend database for data

Theoretical Concepts:
Day 3 introduces the concept of control flow, which allows programs to execute certain code blocks
conditionally or repeatedly, instead of running line-by-line from top to bottom only. This gives our
programs “brains” – the ability to make decisions and perform tasks multiple times.
Conditionals (If Statements):
We use if statements to execute code only if a condition is True. Syntax:
if condition:
# code block to execute if condition is True
elif another_condition:
# code if the first condition was False, but this one is True
else:
# code if none of the above conditions were True

We explain comparison operators used in conditions: == (equals), != (not equals), > , < , >= ,
<= . We also cover logical operators: and , or , not for combining conditions. For example:
x = 10

Loops:
Loops allow us to repeat code. There are two main loop types in Python: - for loops – used to iterate
over a sequence (like a list, range of numbers, characters in a string, etc.). - while loops – repeat as
long as a condition remains True.
A for loop example using Python’s built-in range() function to iterate over a range of numbers:
# Print numbers 1 to 5
for i in range(1, 6):
print(i)
This will print 1 2 3 4 5 (each on a new line). We explain that range(a, b) generates numbers from a
(inclusive) to b (exclusive). If omitted, it starts at 0 by default. So range(5) would produce 0,1,2,3,4.
We also mention range(start, stop, step) for completeness, so they know it exists (e.g.,
range(0, 10, 2) gives even numbers 0,2,4,6,8).
We show iterating over a list:
fruits = ["apple", "banana", "cherry"]
for f in fruits:
print(f)
This loop will print each fruit name. The loop variable f takes each value in the list in turn.

At this point, your code in earlier days might be getting longer. Day 4 introduces functions, which are a

Defining a Function:
In Python, we define a function using the def keyword:

Return Values:
By default, a function returns None if it doesn’t hit a return statement. Often we want a function to
compute something and give back a result. For example:

Here, the function add takes two numbers and returns their sum. The return statement exits the
function and sends the value back to the caller. We emphasize that once return is executed, the
function ends – code after return in the function body won’t run.

def say_hello():

if n % 2 == 0:

Variable Scope:
We introduce the concept of local variables (variables defined inside a function) versus global
variables (defined at the top level of a script). A variable inside a function (like a and b in add , or
n in is_even ) is local to that function – it doesn’t exist outside the function. For example:
def f():
x = 5 # x is local to f
print(x)
f()
print(x) # This will cause an error because x is not defined outside f
This concept of scope is important to avoid confusion when writing larger programs. We generally use
function parameters and return values to get data in and out of functions, rather than relying on global
variables. Global variables (declared at top of file) can be accessed inside functions, but to modify them
you’d need to declare them global within the function (we rarely recommend this for beginners;
instead design functions to return values that you then assign to globals if needed).
Organizing Code into Multiple Functions:
We demonstrate how a program can call multiple functions and how functions can call other functions.
For instance, building on previous days:
def calculate_factorial(n):
"""Calculate factorial of n (n!)."""
result = 1
for i in range(1, n+1):
result *= i
return result
def main():
num = int(input("Enter a positive integer: "))
fact = calculate_factorial(num)
print(f"The factorial of {num} is {fact}")
# Call the main function to run the program
main()
Here main() function drives the program using a helper function calculate_factorial . This
separation of concerns is useful: calculate_factorial knows how to compute a factorial, and
main handles input/output. This makes testing easier too (we could test calculate_factorial
independently of user input).

Theoretical Concepts:
On Day 5, we introduce fundamental data structures which allow you to store collections of data.
Python’s most versatile data type is the list. A list is an ordered collection of elements (which can be of
any type, and the list can mix types, though usually they’re homogeneous). Lists are defined with square
brackets [] . For example:
numbers = [10, 20, 30, 40]
words = ["hello", "world"]
mixed = [1, "two", 3.0]
We explain that list elements are indexed starting at 0. So in numbers , numbers[0] is 10,
numbers[1] is 20, etc. Negative indices access from the end ( numbers[-1] would be 40). We
demonstrate how to slice lists to get sublists:
print(numbers[1:3]) # [20, 30] (slice from index 1 up to but not including

File I/O (Input/Output):

to zero length). - "a" = append (write without truncating, starts at end of file if exists). - "r+" = read
and write.

What is OOP?
Object-Oriented Programming is a paradigm where we organize code into objects – each object is an
instance of a class and bundles data (attributes) and behaviors (methods) that belong together. This can
make managing complex programs easier by modeling concepts in code more naturally.
We’ve been using objects already (everything in Python is an object). For example, a string is an object
of class str with methods like .upper() , .find() , etc. When you do "hello".upper() , you’re
calling a method of the string object.
Defining a Class:
In Python:

# initializer (constructor) method

self.age = age
def bark(self):
print(f"{self.name} says: Woof!")
Here we define a class Dog with an __init__ method and a regular method bark . Points to
explain: - __init__ is a special method that runs when a new object is created. It is used to initialize
the object’s attributes. The parameter self refers to the instance itself (like “this” in some other
languages), and we use it to set attribute values. When we create a Dog, we might do: d =
Dog("Rex", 5) – Python will call Dog.__init__(d, "Rex", 5) internally to set up the object. -
We attach attributes to self , e.g., self.name = name creates an attribute name for that instance.
- The bark method uses self.name to access the dog’s name and prints a message. self must
be the first parameter of any instance method, and it is automatically provided when you call the
method on an object (so d.bark() calls Dog.bark(d) behind the scenes).

How the Web Works (Crash Course):
A client (usually a web browser) sends an HTTP request to a server, which processes it and returns an
HTTP response. The response typically includes a status code (200 for success, 404 for not found, etc.)
and the content (e.g., an HTML page). The browser then renders the HTML for the user. We have a
server (our Flask app) running that listens for requests on a certain URL (like http://localhost:
5000/ ) and returns responses.

Simplified HTTP request-response cycle between a client (browser) and a server. The client sends a request
(e.g., asking for a web page), the server processes it (perhaps interacting with a database or application logic),
and then sends back an HTTP response (often HTML content) for the browser to display 7 .
Key terms: - HTTP Methods: GET (for retrieving information), POST (for sending data like form
submissions), etc. We’ll mainly use GET for showing pages and POST for form submissions. - URL/
Route: The path in the web address corresponds to a route on the server (e.g., /about or /login ). -
Status Code: Part of the HTTP response (200 OK, 404 Not Found, 500 Server Error, etc.).
We won’t dive too deep into HTTP details right now, but this context is important so you understand

What is Flask?
Flask is a micro web framework for Python. “Micro” because it’s lightweight and minimal, giving you
the core tools to build web apps (routing, request/response handling, etc.) without much overhead.
Despite being “micro,” Flask is powerful and has many extensions for database integration,
authentication, etc. It's designed to make getting started quick and easy 8 .
In essence, Flask will: - Start a web server for you (for development). - Map URL routes to Python
functions you write (these are called view functions or route handlers). - Handle details of HTTP, so in
Python you can work with request data easily and return responses. - Provide a template engine (Jinja2)
for generating HTML dynamically (we will use this in Week 3). - Remain flexible – you choose what
components to add (like a database layer, etc.).

What are Templates?
In Flask, instead of returning strings with HTML directly from view functions (which can get messy for
anything beyond a trivial message), we use template files – which are basically HTML files with
placeholders for dynamic content. This follows the MVC (Model-View-Controller) or similar separation
principles: our Python functions act as controllers, templates are the view (UI), and data (model) comes
from DB or logic.
Flask uses Jinja2 as its template engine. Jinja allows us to write placeholders like {{ variable }} in
HTML, which Flask will replace with actual values when rendering the template. It also allows control
flow in templates with {% ... %} tags (for loops, if conditions, etc.).

So far, we used a Python list or a file to store data. In a real server environment, when the app restarts,
that list is cleared, and if multiple server instances, they don't share that list. A database solves
persistent storage and concurrency. SQLite is a simple SQL database stored in a single file, perfect for
small apps and testing.
