# ACME Bank - Access Control Policy (Excerpt)

Effective Date: 2025-04-01 Owner: IAM Team

## Requirements
- MUST: Enforce MFA for all privileged accounts.
- MUST: Review access for admin groups monthly.
- SHOULD: Implement just-in-time access for production systems where feasible.

## Access Review Schedule (Table)

| Group          | Frequency | Evidence        |
|----------------|-----------|-----------------|
| Admin          | Monthly   | Attestation report |
| Database       | Monthly   | Ticket export   |
| Privileged Apps| Quarterly | Control log     |
