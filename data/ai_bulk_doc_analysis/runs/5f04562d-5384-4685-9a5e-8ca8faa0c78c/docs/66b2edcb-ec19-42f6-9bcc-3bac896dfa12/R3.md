# R0 Policy Document Summary

This policy document covers access control requirements for ACME Bank. Key points include:

- Enforce MFA for all privileged accounts
- Review access for admin groups monthly
- Implement just-in-time access for production systems where feasible
- Defined access review schedule and evidence requirements for different user groups

## Obligations
