# Document Summary

This 1-month intensive bootcamp teaches Python and Flask web development from scratch. Week 1 covers Python fundamentals (syntax, data types, control flow, functions, data structures). Week 2 introduces developer tools (Git/GitHub, file I/O, exception handling, OOP). Week 3 focuses on Flask web development (templates, forms, databases). Week 4 culminates in a capstone full-stack project with deployment, emphasizing code quality, testing, and documentation throughout.
