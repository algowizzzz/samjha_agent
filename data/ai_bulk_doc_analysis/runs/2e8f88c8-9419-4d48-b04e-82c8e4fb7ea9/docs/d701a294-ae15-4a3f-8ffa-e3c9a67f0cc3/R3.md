# R0 Policy Document Summary

This is an excerpt from the ACME Bank Access Control Policy, effective April 1, 2025. The policy outlines several key requirements:

1. MUST: Enforce MFA for all privileged accounts.
2. MUST: Review access for admin groups monthly.
3. SHOULD: Implement just-in-time access for production systems where feasible.

The policy also includes an "Access Review Schedule" table that specifies the review frequency and evidence for different user groups.
