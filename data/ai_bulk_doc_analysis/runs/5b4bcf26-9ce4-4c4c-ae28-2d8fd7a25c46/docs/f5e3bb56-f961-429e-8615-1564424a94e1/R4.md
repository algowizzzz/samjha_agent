## Content Structure Summary

### **Week 1: Python Fundamentals** (Days 1-5)
- Environment setup, data types, variables, strings
- Control flow (conditionals, loops)
- Functions and code organization
- Data structures (lists, dictionaries)
- **Deliverable:** Mini-Project 1 - "Guess the Number" Game

### **Week 2: Intermediate Python & Developer Tools** (Days 1-5)
- CLI mastery and Git/GitHub version control
- File I/O and exception handling
- Object-Oriented Programming (OOP)
- Flask introduction and web concepts
- **Deliverable:** Mini-Project 2 - Console Contact Book

### **Week 3: Web Application Development** (Days 1-5)
- HTML & Jinja2 templating
- User input and form handling
- SQLite database integration
- Best practices and deployment preparation
- **Deliverable:** Capstone project planning and submission

### **Week 4: Capstone Project & Deployment**
- Full-stack Flask web application with authentication
- CRUD operations and database integration
- Testing, documentation, and deployment
- **Evaluation Criteria:** Completeness, correctness, UX, code quality, deployment
