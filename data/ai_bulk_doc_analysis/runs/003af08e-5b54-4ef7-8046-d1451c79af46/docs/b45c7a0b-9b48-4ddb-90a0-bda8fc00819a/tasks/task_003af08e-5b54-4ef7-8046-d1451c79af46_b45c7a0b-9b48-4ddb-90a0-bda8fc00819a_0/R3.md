# Combined 5Ws Analysis: PDF Text Extraction Issue (TCK-001)

## WHO
- **Primary Actor**: Northwind (Customer/Document Owner)
- **Affected Parties**: 
  - Document processing system/team
  - End-users attempting to extract text
  - Support team (assigned to TCK-001)
- **Decision Makers**: Northwind management, Support leadership
- **Technical Stakeholders**: Development team, OCR specialists

## WHAT
- **Core Problem**: PDF documents contain scanned pages (image-based content) without embedded text layer
- **Functional Impact**: Text extraction fails completely; no searchable or machine-readable content available
- **Business Impact**: Workflow delays, reduced document accessibility, potential compliance issues
- **Issue Classification**: Technical/Document Processing Failure
- **Severity Level**: High Priority (TCK-001)
- **Scope**: Affects document processing pipeline and downstream operations

## WHERE
- **Physical Location**: Northwind's document repository/storage system
- **System Location**: Text extraction module/service
- **Process Stage**: Document ingestion/processing phase
- **Affected Workflow**: Northwind's document management and processing workflow
- **Technical Layer**: PDF parsing and OCR processing layer

## WHEN
- **Discovery Time**: Current/Active (no specific timestamp provided)
- **Urgency**: Immediate (High priority designation)
- **Duration**: Ongoing until resolution
- **Business Hours Impact**: Likely affecting current operations
- **SLA Requirement**: High priority suggests expedited resolution timeline

## HOW
- **Root Cause**: Scanned PDFs lack text layer; image-only format prevents algorithmic text extraction
- **Failure Mechanism**: 
  - Standard text extraction tools cannot read image content
  - No OCR capability currently enabled in system
  - Document format incompatible with existing extraction logic
- **Resolution Approaches**:
  1. Implement OCR (Optical Character Recognition) processing
  2. Request Northwind resubmit text-enabled PDFs
  3. Deploy hybrid extraction (OCR + standard extraction)
  4. Configure preprocessing pipeline for scanned documents
- **Dependencies**: OCR library availability, processing capacity, customer cooperation

**Northwind is experiencing a high-priority document processing failure (TCK-001)** where scanned PDF submissions cannot be processed through the standard text extraction system. This requires immediate technical intervention to either implement OCR capabilities, establish document format requirements with the customer, or deploy a hybrid processing solution to restore workflow functionality and prevent further operational delays.

2. Assess OCR implementation feasibility and resource requirements
