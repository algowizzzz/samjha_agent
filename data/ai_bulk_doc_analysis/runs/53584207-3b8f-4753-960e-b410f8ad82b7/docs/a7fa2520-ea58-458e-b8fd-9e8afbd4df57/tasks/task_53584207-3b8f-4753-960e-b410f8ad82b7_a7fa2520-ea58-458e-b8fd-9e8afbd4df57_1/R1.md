## Analysis

### 1. Category
**Compliance Review & Document Processing**

This task involves extracting requirement statements from documentation and performing a gap analysis, which falls under compliance and regulatory documentation work.

---

### 2. Key Requirements

- **Extract MUST/SHOULD statements**: Identify and isolate mandatory (MUST) and recommended (SHOULD) requirements from source documentation
- **Generate gap summary**: Analyze the extracted requirements and document any gaps between current state and required state
- **Structured output**: Deliver findings in a clear, organized format suitable for compliance tracking

---

### 3. Complexity Assessment

**Medium Complexity**

**Rationale:**
- Requires understanding of requirement classification standards (MUST vs. SHOULD terminology)
- Involves both extraction and analytical work (gap identification)
- Assumes source documentation is available but may require interpretation
- Not highly complex, but more involved than simple data extraction

---

### 4. Dependencies

- **Source Documentation**: The original document(s) containing requirements that need to be analyzed
- **Gap Criteria Definition**: Clear definition of what constitutes a "gap" in this context
- **Output Format Specification**: Template or format requirements for the gap summary report
- **Domain Context**: Understanding of Contoso's business domain and compliance requirements
- **Reference Standards**: Any applicable compliance frameworks or standards (e.g., ISO, regulatory requirements)
