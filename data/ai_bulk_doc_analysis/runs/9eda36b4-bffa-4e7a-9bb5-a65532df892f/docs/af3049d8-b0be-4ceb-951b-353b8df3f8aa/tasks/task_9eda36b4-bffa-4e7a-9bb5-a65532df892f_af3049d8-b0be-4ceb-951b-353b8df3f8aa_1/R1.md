## Analysis

### 1. Category
**Compliance Review & Document Processing**

This task involves extracting requirements from documentation and performing a gap analysis, which falls under compliance and requirements management work.

---

### 2. Key Requirements

- **Extract MUST requirements**: Identify and catalog all mandatory requirements from source documentation
- **Extract SHOULD requirements**: Identify and catalog all recommended/desired requirements from source documentation
- **Generate gap summary**: Analyze the difference between current state and required state, documenting gaps and discrepancies

---

### 3. Complexity Assessment

**Medium Complexity**

**Rationale:**
- Requires understanding of requirement classification standards (MUST vs. SHOULD)
- Demands careful document review and accurate categorization
- Gap analysis requires comparative analysis between requirements and current implementation
- However, the scope appears focused and well-defined, preventing higher complexity rating

---

### 4. Dependencies

- **Source documentation**: The specific document(s) containing requirements to be analyzed
- **Current state baseline**: Information about existing implementation or current capabilities for gap comparison
- **Requirements classification standards**: Definition of what constitutes MUST vs. SHOULD in Contoso's context
- **Gap analysis template/format**: Preferred format for presenting the gap summary results
- **Subject matter expert**: Potential need for Contoso stakeholder input to validate extracted requirements
