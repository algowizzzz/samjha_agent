# Document Summary

This 1-month intensive software development bootcamp teaches Python and Flask web development. Week 1 covers Python fundamentals (syntax, data types, control flow, functions). Week 2 introduces file I/O, exception handling, OOP, and Git version control. Week 3 focuses on Flask web development with templates, forms, and SQLite database integration. Week 4 culminates in a full-stack capstone project with user authentication, CRUD operations, and deployment to a hosting platform.
