# Document Summary

This 1-Month Software Development Bootcamp coursebook teaches Python and Flask web development to beginners. It covers four weeks: Week 1 focuses on Python fundamentals (syntax, data types, control flow, functions); Week 2 introduces intermediate Python, file I/O, OOP, and Git version control; Week 3 covers Flask web development with templates, forms, and SQLite databases; Week 4 culminates in a full-stack capstone project with deployment. Each week includes daily lessons, hands-on labs, and mini-projects, progressing from console applications to a deployed web application.
