# R0 Policy Report

## Summary

This report analyzes the ACME Bank Access Control Policy, which covers requirements for access management and review. The key points are:

- The policy has 3 clear obligations:
  1. MUST: Enforce MFA for all privileged accounts
  2. MUST: Review access for admin groups monthly 
  3. SHOULD: Implement just-in-time access for production systems where feasible
- There is one potential gap around the implementation details for just-in-time access, which could lead to inconsistent application.
- Two clarifying questions are provided to address this gap.

## Obligations

| Type | Statement | Section |
| --- | --- | --- |
| MUST | Enforce MFA for all privileged accounts. | Requirements |
| MUST | Review access for admin groups monthly. | Requirements |

## Gaps

| Severity | Gap | Related Obligation |
| --- | --- | --- |
| Medium | The policy does not specify how 'just-in-time access' should be implemented or what 'feasible' means in this context. More details are needed to ensure consistent implementation. | Implement just-in-time access for production systems where feasible. |

## Questions

1. What criteria should be used to determine if just-in-time access is 'feasible' for a production system?
2. How should just-in-time access be implemented for production systems (e.g. technical controls, approval workflows, etc.)?
