# Document Type Analysis

**Document Type:** Educational Coursebook / Training Manual

**Rationale:** This is a structured 4-week software development bootcamp curriculum designed as a comprehensive learning guide. It contains sequential daily lessons with learning objectives, theoretical concepts, hands-on labs, guided exercises, and projects—characteristic of an instructional coursebook rather than a policy, SOP, or procedure document. The document serves as a complete educational resource for self-paced or instructor-led training.
