# R0 Policy Report

## Summary

The ACME Bank Access Control Policy outlines key requirements and access review procedures. The policy defines three main obligations:

1. MUST: Enforce MFA for all privileged accounts.
2. MUST: Review access for admin groups monthly. 
3. SHOULD: Implement just-in-time access for production systems where feasible.

The policy also includes an access review schedule table that specifies the frequency and evidence for different user groups.
