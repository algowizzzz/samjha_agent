## Key Content Overview

The specification defines a three-panel layout application with the following structure:

### Panel 1 - Documents (Ingestion & Conversion)
- PDF upload functionality (other formats coming soon)
- Document list with status tracking
- Auto-conversion after upload

### Panel 2 - Prompt Chain (Configuration)
- Saved chain selector with cards showing name, description, and step count
- Read-only chain detail view
- No inline editing to maintain clean UI

### Panel 3 - Run & Output (Execution)
- Run button with smart enabling conditions
- Live progress tracking per document
- Download capabilities for individual or all outputs

### Design Principles
1. Clarity over power
2. Progress visibility for async operations
3. One primary action per panel
4. Deterministic feel
5. Visible failures with clean recovery

The specification emphasizes simplicity, avoiding chat-style interfaces, inline editors, and complex wizards. Success is measured by first-time user ability to complete the full workflow without confusion.
