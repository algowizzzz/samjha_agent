# Actionable Recommendations for Ticket TCK-002

## 1. Recommended Approach

1. **Clarify Scope and Requirements**
   - Contact Contoso to confirm which document(s) require MUST/SHOULD extraction
   - Identify the specific system, product, or process area in scope
   - Determine applicable compliance frameworks or standards (ISO, regulatory, internal policy)

2. **Define Extraction Criteria**
   - Establish clear definitions for MUST vs. SHOULD requirement classifications
   - Document any specific keywords, patterns, or indicators to identify requirements
   - Define what constitutes a "gap" in Contoso's context (missing implementation, non-compliance, deviation, etc.)

3. **Obtain Source Documentation**
   - Request all relevant source documents from Contoso
   - Confirm document format, version, and any access restrictions
   - Verify document completeness and currency

4. **Extract MUST Requirements**
   - Systematically review source documentation
   - Identify and catalog all mandatory (MUST) requirements
   - Document requirement ID, description, and source location

5. **Extract SHOULD Requirements**
   - Identify and catalog all recommended (SHOULD) requirements
   - Document requirement ID, description, and source location
   - Distinguish between SHOULD and MUST to avoid misclassification

6. **Conduct Gap Analysis**
   - Compare extracted requirements against current state/implementation
   - Identify missing, incomplete, or non-compliant items
   - Categorize gaps by severity and impact

7. **Prepare Gap Summary**
   - Compile findings in agreed-upon format (report, spreadsheet, matrix)
   - Provide executive summary with key findings
   - Include recommendations for gap remediation

8. **Review and Deliver**
   - Validate findings with Contoso stakeholders
   - Address feedback and clarifications
   - Deliver final deliverable with supporting documentation
