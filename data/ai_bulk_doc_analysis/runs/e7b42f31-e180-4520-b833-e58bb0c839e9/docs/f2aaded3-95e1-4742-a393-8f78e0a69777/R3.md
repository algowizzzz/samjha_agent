# R0 Policy Report

## Summary
This policy covers access control requirements for ACME Bank, including mandatory use of multi-factor authentication (MFA) for privileged accounts, monthly review of admin group access, and guidance on implementing just-in-time access for production systems.

## Obligations

| Type | Statement | Section |
| --- | --- | --- |
| MUST | Enforce MFA for all privileged accounts. | Requirements |
| MUST | Review access for admin groups monthly. | Requirements |
| SHOULD | Implement just-in-time access for production systems where feasible. | Requirements |

## Gaps

| Severity | Gap | Related Obligation |
| --- | --- | --- |
| Medium | The policy does not provide any details on how to implement just-in-time access or what 'feasible' means in this context. More guidance is needed. | Implement just-in-time access for production systems where feasible. |
